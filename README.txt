# Para Stiven ♡ — aventura romántica interactiva

1. Abre `index.html` en un navegador para probarla.
2. La canción está configurada con el video de YouTube Music que compartiste (ID `mskcCXoMFtQ`).
3. Por las restricciones de reproducción automática de los navegadores, la música se inicia al pulsar **Comenzar aventura**.
4. Las fotos están en `fotos/`.

## Publicarla gratis con GitHub Pages
- Crea un repositorio público en GitHub.
- Sube `index.html` y la carpeta `fotos`.
- Ve a Settings → Pages → Deploy from a branch → selecciona `main` y `/ (root)`.
- GitHub publicará una URL `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

La documentación oficial de GitHub Pages explica estos pasos.
